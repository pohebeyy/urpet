# Система учёта заявок (Request System)
Учебный проект по дисциплине «Технологии разработки программного обеспечения» (Лабораторные работы 1-5).
**Назначение:** Регистрация, маршрутизация и контроль исполнения внутренних заявок.
**Архитектура:** Слоистая (Controller -> Service -> Repository -> Database). База данных: SQLite.
