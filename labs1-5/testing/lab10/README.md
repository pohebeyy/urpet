# Лабораторная работа №10 — Автоматизация тестирования

## 1. Выбранные критические сценарии для автоматизации
На основе тест-плана ЛР №9 для автоматизации отобраны 11 проверок, покрывающих создание заявок, поиск, обновление статусов, валидацию и регрессию дефектов.
Они проверяют слой бизнес-логики и HTTP-контракт, работают на изолированной in-memory SQLite базе.

## 2. Команда запуска автоматических тестов
Через Docker-контейнер:
    sudo docker-compose exec -T api pytest testing/lab10/test_app.py -v
